# 윤슬 YUN:SEUL — 공식 웹사이트 (포트폴리오 프로젝트)

> 한국의 아름다움을 일상 속에서 · Korean beauty, worn every day

전통 모티프 데일리 액세서리 브랜드 **윤슬**의 반응형 웹사이트입니다. 국문/영문 전환, 컬렉션·제품 상세, 장바구니(데모), 기프트 가이드를 포함합니다. 실제 결제는 이루어지지 않습니다.

### 페이지별 역할과 타깃 연결

| 페이지 | 역할 | 주요 타깃 (기획서 기준) |
|---|---|---|
| Home | 첫인상, 브랜드 무드 전달, 컬렉션으로 유도 | 전체 |
| About | 브랜드 철학과 아이덴티티의 근거 제시 | 메인 타깃 — 디자인에 담긴 서사를 중시하는 2030 |
| Collections / Detail | 모티브 스토리 → 제품으로 연결 | 메인 타깃 |
| Product | 구매 결정에 필요한 정보 (소재·사이즈·관리) | 메인 타깃 |
| Gift | 패키지·예산별 추천으로 선물 구매 지원 | 서브 타깃 — 기프트 슈머 |
| Journal | 전시·이벤트로 오프라인 경험 연결, 화보로 SNS 아카이빙 욕구 자극 | 메인 타깃 — 감도 높은 공간을 소비하는 2030 |
| Contact + EN 전환 | 해외 배송, 영문 보증서 안내 | 서브 타깃 — 글로벌 익스팬더 |

### 주요 사용자 흐름

1. **탐색 → 구매**: Home → 컬렉션 → 컬렉션 상세 → 제품 상세 → 장바구니 → 결제(데모 안내)
2. **선물 구매**: Home 기프트 티저 → Gift → 예산 선택 → 제품 상세 (메시지 카드 체크) → 장바구니
3. **브랜드 이해**: Home 브랜드 정의 → About → 컬렉션
4. **해외 고객**: 헤더 EN 전환 → 전 페이지 영문 → Help (해외 배송 FAQ)

## 2. 디자인 시스템 요약

| 토큰 | 값 | 사용처 |
|---|---|---|
| Black | `#111111` | 메인 배경 |
| Jade Green | `#A7D7B2` | 로고, 슬로건, 버튼, 라인 그래픽 |
| Gold | `#C9A24A` | 기프트·시그니처 등 특별한 순간에만 |
| Pearl | `#EEECE7` | 제품 사진이 놓이는 밝은 섹션 |
| Iridescent | 그라데이션 | Hero 인터랙션에서 커서 주변에만 (가이드의 "제한적 사용" 반영) |

- 서체: Pretendard (본문) · 조선일보명조 (보조 제목) · **310 안삼열** (슬로건, 메뉴, 페이지 제목, 컬렉션명, 전시명)
  - 310 안삼열은 산돌 구독 서체라 웹폰트 사용이 허용되지 않아, 일러스트레이터에서 윤곽선으로 만든 SVG를 `js/type.js`에 넣어 '이미지'로 사용합니다. 서체 파일은 사이트에 포함되지 않습니다.
  - 새 문구가 필요하면 일러스트에서 윤곽선 SVG를 만들어 `js/type.js`에 추가합니다.
- 레이아웃 원칙: 무드·스토리는 블랙, 제품 사진은 펄 배경. 촬영 톤(블랙 스튜디오 / 화이트 제품컷)을 그대로 웹 구조로 옮김.
- 시그니처 인터랙션: Hero의 **물 위의 빛** — 그래픽 모티브 type C(수평 선 레이어)를 캔버스로 구현. 커서가 닿는 곳의 빛이 밝아지며 자개빛으로 변함. `prefers-reduced-motion` 설정 시 정지.

## 4. 실행 방법

- 가장 간단하게: `index.html`을 브라우저로 열기
- 로컬 서버: 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000`
- 배포: GitHub 저장소에 올린 뒤 Settings → Pages → Branch `main` / root 선택

## 5. 수정 가이드

- **제품 추가/가격 변경**: `js/data.js`의 `YS.products`에 항목 추가. 이미지 파일명은 `assets/img/` 안의 이름(확장자 제외).
- **카피 수정**: `js/data.js`의 `YS.t` — 각 항목에 `ko`, `en`이 함께 있습니다.
- **색상 변경**: `css/style.css` 맨 위 `:root` 변수.

## 6. 참고

- 제품 가격·소재·사이즈는 포트폴리오용 가상 데이터입니다.
- 로고 워드마크는 기획서 이미지에서 추출했습니다. 원본 일러스트 파일에서 텍스트를 윤곽선으로 만든(Create Outlines) SVG로 교체하면 더 선명해집니다 (`assets/brand/wordmark-ko.png`, `wordmark-en.png`).
- 웹폰트(Pretendard, 조선일보명조)는 CDN에서 불러옵니다. CDN을 쓸 수 없는 환경에서는 Noto Sans KR / 나눔명조로 대체됩니다.

## 홈 룩북 슬라이더 (.lbs)
레퍼런스(nidatabba.com) 하단 슬라이더 구조: 큰 문장 위로 사진 3장 구성 슬라이드가 겹쳐 올라오고, 무한히 좌측으로 흐름(데스크톱 약 120px/s, 모바일 60px/s). 마우스/터치로 끌어 던질 수 있으며 놓은 방향으로 계속 흐름. 위치는 lerp(0.15)로 부드럽게 따라감. 제목은 100px 아래에서 0.7s 페이드업, 스크롤을 되돌리면 다시 재생. 화면 밖에서는 rAF 정지. 사진에 마우스를 올리면 프레임 안에서 1.1배 확대(0.3s ease-out, 원본과 동일). 사진 크기는 --k(.84)로 일괄 조절.

## 홈 브랜드정의 모션 (원본 .home-text-images 실측값)
- 제목·링크: fade-up 50px / 0.7s ease-out. 화면 가운데(50%)에 닿을 때 재생 (원본보다 약간 늦춤, 요청 반영). 본문은 정지.
- 사진: 사진 열이 화면 75%(모바일 90%) 지점에 닿으면 1.2s 동안 부드럽게 페이드인 (큰 사진은 50px 아래에서 함께 떠오름). 요청에 따라 원본의 아래→위 와이프 대신 페이드 사용.
- 작은 사진: 패럴랙스 translateY 100%→0, 사진 높이의 2배만큼 스크롤하는 동안 (원본 parallax-image.js 공식).
- 모두 화면 아래로 다시 내려가면 초기화되어 반복 재생.
- 등장 시점 계산은 스크롤 위치(getBoundingClientRect) 기반 `watchReveal()`로 처리. IntersectionObserver의 rootMargin은 다른 출처의 iframe(아티팩트 뷰어) 안에서 무시되어 모션이 화면 밖에서 끝나버리는 문제가 있었음.

## JOURNAL · LOOKBOOK (jurijewelry.com 홈 레이아웃)
자유 배치: 사진마다 보드 너비 대비 % 좌표(x, y, w)로 놓아 겹침·3장 묶음·가까운/먼 간격을 섞음(레퍼런스 느낌). 사진은 원본 비율 그대로(잘림 없음). 컬렉션 대표 사진 3장에 이름·제품 수(회색 명조). 모바일은 2열 지그재그.
모션: ① 인트로 — 첫 8장이 화면 중앙에 차례로 쌓였다가(0→0.6배) 하나씩 자기 자리로 내려가 안착(2s, power3.inOut, 0.3s 간격), 그동안 스크롤 잠금.
② 자동 스크롤 — 가만히 있어도 약 21px/s로 천천히 내려감(레퍼런스 측정값). 휠·터치·키 입력 시 멈추고 0.6초 뒤 재개, 룩북 끝에서 정지.
③ 화면 중앙 고정 심볼 — 사진 뒤, 불투명도 7%.
데이터: YS.lookbookBoard (js/data.js).
